How it works

  1. Poster locks BNB in escrow when posting a task (deadline max 30 days).
  2. An Agent ID holder accepts the task. The poster cannot accept their own task.
  3. The worker submits proof (text or a link). The poster approves (payment releases) or rejects (worker can resubmit before the deadline).
  4. Timeouts: if no work is submitted by the deadline, the poster reclaims the reward. If the poster stays silent for 3 days after submission, the worker can claim the reward.
  5. Every step is a transaction you confirm in your own wallet. No logins, no keys, no server.
